# 🎮 AI Quiz Arena

### An Interactive Artificial Intelligence Quiz Application

AI Quiz Arena is an interactive, gamified quiz application developed using Python and Streamlit as part of the Artificial Intelligence coursework at CHRIST University.

The application aims to make learning Artificial Intelligence more engaging through different question formats, varying difficulty levels, and an interactive gaming-inspired interface.

## ✨ Features

- **50+ Questions:** Covers important concepts from Artificial Intelligence Units I and II.
- **Multiple Question Formats:** MCQs, True/False, Assertion–Reason, Fill in the Blanks, Match the Following, and scenario-based questions.
- **Difficulty Levels:** Choose between different levels of difficulty.
- **Application-Based Learning:** Includes real-world AI scenarios and problem-solving questions.
- **Interactive Interface:** A modern, dark-themed gaming dashboard.
- **Performance Tracking:** View your quiz score and results after completion.

## 📚 Topics Covered

- Foundations and Applications of AI
- Turing Test
- Intelligent and Rational Agents
- Agents and Environments
- Problem Formulation and State Space Search
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Iterative Deepening Search
- Hill Climbing and Its Variations
- Heuristic Search and Best-First Search
- Constraint Satisfaction Problems (CSP)
- Means-End Analysis

## 🚀 How to Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/Sonal-Shaw/AI-Quiz-Arena.git
```

**2. Navigate to the project directory**

```bash
cd AI-Quiz-Arena
```

**3. Install the required dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
streamlit run app.py
```

The application will open in your default browser.
